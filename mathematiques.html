Leçon 1 : Ensembles de nombres et intervalles

Objectifs : reconnaître les ensembles de nombres et utiliser les intervalles.

1. Les ensembles de nombres

  • ℕ : entiers naturels : 0, 1, 2, 3...
  • ℤ : entiers relatifs : -4, -2, 0, 3...
  • 𝔻 : nombres décimaux : 2,5 ; -3,75...
  • ℚ : nombres rationnels, qui s'écrivent comme une fraction d'entiers.
  • ℝ : nombres réels, comprenant les rationnels et les irrationnels.

ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ.

Exemple : -5 appartient à ℤ, 𝔻, ℚ et ℝ. √2 appartient à ℝ mais pas à ℚ.

2. Les intervalles

  • [a ; b] : bornes incluses.
  • ]a ; b[ : bornes exclues.
  • [a ; b[ : a inclus, b exclu.
  • ]a ; b] : a exclu, b inclus.
x ∈ [2 ; 5] signifie 2 ≤ x ≤ 5.
x ∈ ]2 ; 5[ signifie 2 < x < 5.

3. Exercices corrigés

Dans quels ensembles se trouve -8 ?
-8 appartient à ℤ, 𝔻, ℚ et ℝ, mais pas à ℕ.
Traduire x ∈ [3 ; 7[.
3 ≤ x < 7.

Leçon 2 : Calcul numérique et puissances

Objectifs : respecter les priorités opératoires et utiliser les puissances.

1. Les priorités opératoires

On effectue d'abord les parenthèses, ensuite les puissances, puis les multiplications et divisions, enfin les additions et soustractions.

A = 3 + 2 × 5
A = 3 + 10
A = 13.

2. Les puissances

2³ = 2 × 2 × 2 = 8.

  • aᵐ × aⁿ = aᵐ⁺ⁿ
  • aᵐ ÷ aⁿ = aᵐ⁻ⁿ (a non nul)
  • (aᵐ)ⁿ = aᵐⁿ
  • a⁰ = 1 (a non nul)
  • a⁻ⁿ = 1/aⁿ (a non nul)

3. Notation scientifique

Un nombre non nul s'écrit a × 10ⁿ avec 1 ≤ |a| < 10.

45 000 = 4,5 × 10⁴.
0,0032 = 3,2 × 10⁻³.

4. Exercices corrigés

Calculer 5 + 3 × 4.
5 + 12 = 17.
Simplifier 10³ × 10².
10³ × 10² = 10⁵ = 100 000.

Leçon 3 : Calcul littéral et factorisation

Objectifs : réduire, développer et factoriser une expression.

1. Réduction

Réduire consiste à regrouper les termes semblables.

4x + 3 + 2x - 5 = 6x - 2.

2. Développement

a(b + c) = ab + ac.

3(x + 4) = 3x + 12.

3. Factorisation

Factoriser consiste à transformer une somme en produit.

5x + 15 = 5(x + 3).

4. Identités remarquables

  • (a + b)² = a² + 2ab + b²
  • (a - b)² = a² - 2ab + b²
  • (a - b)(a + b) = a² - b²
(x + 3)² = x² + 6x + 9.

5. Exercices corrigés

Développer 2(x + 5).
2x + 10.
Factoriser 4x + 12.
4(x + 3).

Leçon 4 : Équations et inéquations

Objectifs : résoudre des équations et des inéquations simples.

1. Les équations

Une équation est une égalité contenant une inconnue.

2x + 4 = 10
2x = 6
x = 3.

2. Les inéquations

Lorsqu'on multiplie ou divise par un nombre négatif, on inverse le sens de l'inégalité.

-2x > 6
x < -3.

3. Exercices corrigés

Résoudre 3x - 6 = 9.
3x = 15, donc x = 5.
Résoudre x + 4 ≤ 9.
x ≤ 5.

Leçon 5 : Généralités sur les fonctions

Objectifs : calculer une image et déterminer un antécédent.

1. Définition

Une fonction associe à chaque nombre x de son ensemble de définition une image unique f(x).

2. Calcul d'une image

Soit f(x) = 2x + 3.
f(4) = 2 × 4 + 3 = 11.

3. Détermination d'un antécédent

Un antécédent de y est un nombre x tel que f(x) = y.

2x + 3 = 9
2x = 6
x = 3.

4. Représentation graphique

Une fonction peut être représentée par une courbe dans un repère.

5. Exercices corrigés

Soit f(x) = 3x + 2. Calculer f(5).
f(5) = 3 × 5 + 2 = 17.
Soit f(x) = x + 4. Trouver l'antécédent de 10.
x + 4 = 10, donc x = 6.

Leçon 6 : Vecteurs et repérage

Objectifs : déterminer les coordonnées et la norme d'un vecteur.

1. Définition

Un vecteur est caractérisé par une direction, un sens et une longueur appelée norme.

2. Coordonnées

Si A(xA ; yA) et B(xB ; yB), alors AB⃗ = (xB - xA ; yB - yA).

A(2 ; 1) et B(5 ; 4).
AB⃗ = (5 - 2 ; 4 - 1) = (3 ; 3).

3. Norme d'un vecteur

Pour u⃗ = (x ; y), ||u⃗|| = √(x² + y²).

Pour u⃗ = (3 ; 4), ||u⃗|| = √25 = 5.

4. Exercices corrigés

A(1 ; 2) et B(4 ; 6). Calculer AB⃗.
AB⃗ = (3 ; 4).
Calculer la norme du vecteur (6 ; 8).
√(36 + 64) = √100 = 10.

Leçon 7 : Géométrie plane

Objectifs : utiliser les propriétés des triangles, Pythagore et Thalès.

1. Les triangles

  • Équilatéral : trois côtés égaux.
  • Isocèle : deux côtés égaux.
  • Rectangle : un angle droit.

2. Théorème de Pythagore

Dans un triangle ABC rectangle en A : BC² = AB² + AC².

Si les côtés de l'angle droit mesurent 3 cm et 4 cm :
BC² = 9 + 16 = 25
BC = 5 cm.

3. Théorème de Thalès

Si M appartient à [AB], N appartient à [AC] et (MN) est parallèle à (BC), alors :

AM/AB = AN/AC = MN/BC.

AM = 2, AB = 4 et AC = 6.
AN/6 = 2/4.
AN = 3 cm.

4. Exercices corrigés

Un triangle rectangle a deux côtés de 5 cm et 12 cm. Calculer l'hypoténuse.
c² = 25 + 144 = 169, donc c = 13 cm.
AM/AB = 3/5 et AC = 10 cm. Calculer AN.
AN/10 = 3/5, donc AN = 6 cm.

Leçon 8 : Statistiques

Objectifs : calculer une moyenne, une médiane et une étendue.

1. Définition

Les statistiques permettent de recueillir, organiser et analyser des données.

2. La moyenne

Moyenne = somme des valeurs / nombre de valeurs.

Notes : 10 ; 12 ; 14 ; 16.
Moyenne = 52/4 = 13.

3. La médiane

La médiane partage une série ordonnée en deux groupes. Si l'effectif est pair, on fait la moyenne des deux valeurs centrales.

Série : 5 ; 8 ; 10 ; 12 ; 15.
Médiane = 10.

4. L'étendue

L'étendue est la différence entre la plus grande et la plus petite valeur.

Série : 4 ; 6 ; 9 ; 12.
Étendue = 12 - 4 = 8.

5. Exercices corrigés

Calculer la moyenne de 8 ; 10 ; 12 ; 14.
Moyenne = 44/4 = 11.
Calculer l'étendue de 3 ; 7 ; 9 ; 15 ; 18.
Étendue = 18 - 3 = 15.
