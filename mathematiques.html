Niveau : Seconde

Leçon 1 : Les ensembles de nombres

Objectifs :

  • Connaître les différents ensembles de nombres.
  • Distinguer les nombres naturels et relatifs.
  • Identifier les nombres décimaux et rationnels.
  • Comprendre l'ensemble des nombres réels.

I. Les nombres entiers naturels (N)

Les nombres entiers naturels sont les nombres utilisés pour compter.

N = {0 ; 1 ; 2 ; 3 ; 4 ; 5 ; ...}

Exemples : 0, 5, 12, 100.

II. Les nombres entiers relatifs (Z)

Les nombres entiers relatifs comprennent les nombres positifs, les nombres négatifs et zéro.

Z = {... ; -3 ; -2 ; -1 ; 0 ; 1 ; 2 ; 3 ; ...}

Exemples : -5, -2, 0, 7, 12.

III. Les nombres décimaux (D)

Un nombre décimal possède une écriture décimale finie.

Exemples : 2,5 ; 0,75 ; -3,2 ; 4

On peut écrire un nombre décimal sous forme d'une fraction dont le dénominateur est une puissance de 10.

IV. Les nombres rationnels (Q)

Un nombre rationnel est un nombre qui peut s'écrire sous la forme d'une fraction :

a / b avec a et b entiers et b différent de 0.

Exemples :

1/2 = 0,5
3/4 = 0,75
-2/5 = -0,4

V. Les nombres réels (R)

Les nombres réels comprennent les nombres rationnels et les nombres irrationnels.

Exemples :

  • 2
  • 1/3
  • √2
  • π

VI. Inclusion des ensembles

Les ensembles de nombres sont emboîtés :

N ⊂ Z ⊂ D ⊂ Q ⊂ R

Cela signifie que tout nombre naturel est aussi un entier relatif, un nombre décimal, rationnel et réel.

VII. Exemples corrigés

Exemple 1

Le nombre -7 appartient-il à Z ?

Correction :

Oui, car -7 est un nombre entier relatif.

Exemple 2

Le nombre 0,25 est-il rationnel ?

Correction :

0,25 = 25/100 = 1/4

Donc 0,25 appartient à Q.

Exemple 3

Le nombre √2 est-il rationnel ?

Correction :

Non. √2 est un nombre irrationnel. Il appartient à R mais pas à Q.

VIII. Résumé à retenir

  • N : nombres entiers naturels.
  • Z : nombres entiers relatifs.
  • D : nombres décimaux.
  • Q : nombres rationnels.
  • R : nombres réels.
N ⊂ Z ⊂ D ⊂ Q ⊂ R
