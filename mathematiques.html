Leçon 1 : Ensembles de nombres et intervalles

1. Les différents ensembles de nombres

Un ensemble de nombres est un regroupement de nombres qui possèdent certaines propriétés.

  • ℕ : ensemble des entiers naturels : 0 ; 1 ; 2 ; 3 ; ...
  • ℤ : ensemble des entiers relatifs : ... ; -2 ; -1 ; 0 ; 1 ; 2 ; ...
  • 𝔻 : ensemble des nombres décimaux, qui possèdent une écriture décimale finie.
  • ℚ : ensemble des nombres rationnels, qui peuvent s'écrire sous la forme a/b avec b différent de 0.
  • ℝ : ensemble des nombres réels.
ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ

2. Les intervalles

Un intervalle est une partie de la droite réelle comprise entre deux bornes.

  • [a ; b] : les deux bornes sont incluses.
  • ]a ; b[ : les deux bornes sont exclues.
  • [a ; b[ : a est inclus, b est exclu.
  • ]a ; b] : a est exclu, b est inclus.

3. Exemples

Exemple 1 : 3 appartient-il à [2 ; 5] ?
Oui, car 2 ≤ 3 ≤ 5.
Exemple 2 : -2 appartient-il à ]-2 ; 4] ?
Non, car la borne -2 est exclue.

4. À retenir

Les symboles ∈ et ∉ signifient respectivement « appartient à » et « n'appartient pas à ».

Leçon 2 : Calcul numérique et puissances

1. Les priorités opératoires

Dans une expression numérique, on respecte l'ordre suivant :

  1. Les calculs entre parenthèses.
  2. Les puissances.
  3. Les multiplications et divisions.
  4. Les additions et soustractions.
Exemple :
A = 5 + 3 × 2
On effectue d'abord la multiplication :
A = 5 + 6 = 11.

2. Les puissances

Une puissance permet d'écrire plus simplement un produit de facteurs identiques.

aⁿ = a × a × ... × a (n facteurs)

3. Propriétés des puissances

  • aᵐ × aⁿ = aᵐ⁺ⁿ
  • aᵐ / aⁿ = aᵐ⁻ⁿ, si a ≠ 0
  • (aᵐ)ⁿ = aᵐˣⁿ
  • a⁰ = 1, si a ≠ 0
  • a⁻ⁿ = 1/aⁿ, si a ≠ 0
Exemple :
2³ × 2² = 2⁵ = 32.

4. Racines carrées

La racine carrée d'un nombre positif a est le nombre positif dont le carré est égal à a.

√25 = 5 car 5² = 25.

Pour a et b positifs :

  • √(a × b) = √a × √b
  • √(a/b) = √a / √b, si b est positif et non nul.

Leçon 3 : Calcul littéral et factorisation

1. Définition

Le calcul littéral consiste à utiliser des lettres pour représenter des nombres.

Si x représente un nombre, alors 3x signifie 3 multiplié par x. Pour x = 4, on obtient 3x = 3 × 4 = 12.

2. Réduction d'une expression

Réduire une expression consiste à regrouper les termes semblables.

A = 3x + 5x - 2
A = 8x - 2.

3. Développement

Développer consiste à supprimer les parenthèses en utilisant la distributivité.

k(a + b) = ka + kb
A = 3(x + 4)
A = 3x + 12.

4. Factorisation

Factoriser consiste à transformer une somme en produit.

ka + kb = k(a + b)
A = 5x + 15
A = 5(x + 3).

5. Identités remarquables

  • (a + b)² = a² + 2ab + b²
  • (a - b)² = a² - 2ab + b²
  • (a - b)(a + b) = a² - b²
(x + 3)² = x² + 6x + 9.

Leçon 4 : Équations et inéquations

1. Les équations

Une équation est une égalité contenant une ou plusieurs inconnues.

Résoudre une équation consiste à trouver les valeurs de l'inconnue qui rendent l'égalité vraie.

Exemple :
Résoudre 2x + 4 = 10.
2x = 10 - 4
2x = 6
x = 6/2
x = 3.

2. Vérification

On remplace x par 3 dans l'équation initiale :

2 × 3 + 4 = 6 + 4 = 10.

L'égalité est vraie. La solution est donc 3.

3. Les inéquations

Une inéquation est une inégalité qui contient une inconnue.

Les symboles utilisés sont : inférieur à (<), supérieur à (>), inférieur ou égal à (≤), supérieur ou égal à (≥).

Exemple :
Résoudre 2x + 4 < 10.
2x < 6
x < 3.

4. Règle importante

Lorsqu'on multiplie ou divise les deux membres d'une inéquation par un nombre négatif, on inverse le sens de l'inégalité.

-2x < 6
En divisant par -2, on obtient :
x > -3.

Leçon 5 : Généralités sur les fonctions

1. Définition

Une fonction est un procédé qui associe à un nombre x un unique nombre appelé image de x.

On note généralement f(x) l'image de x par la fonction f.

2. Image et antécédent

Soit f(x) = 2x + 3.
L'image de 4 est :
f(4) = 2 × 4 + 3 = 11.
Donc 11 est l'image de 4.

Un antécédent de 11 est un nombre x tel que f(x) = 11.

2x + 3 = 11
2x = 8
x = 4.
Donc 4 est un antécédent de 11.

3. Fonction linéaire

Une fonction linéaire est de la forme :

f(x) = ax

Sa représentation graphique est une droite qui passe par l'origine du repère.

4. Fonction affine

Une fonction affine est de la forme :

f(x) = ax + b

Sa représentation graphique est une droite.

5. Tableau de valeurs

Pour construire un tableau de valeurs, on choisit des valeurs de x puis on calcule leurs images.

Pour f(x) = 2x + 1 :
f(0) = 1
f(1) = 3
f(2) = 5.

Leçon 6 : Vecteurs et repérage

1. Définition d'un vecteur

Un vecteur est caractérisé par :

  • Sa direction.
  • Son sens.
  • Sa norme ou longueur.

2. Coordonnées d'un vecteur

Dans un repère, si A(xA ; yA) et B(xB ; yB), alors :

AB = (xB - xA ; yB - yA)
A(2 ; 1) et B(5 ; 4).
AB = (5 - 2 ; 4 - 1)
AB = (3 ; 3).

3. Égalité de deux vecteurs

Deux vecteurs sont égaux lorsqu'ils ont la même direction, le même sens et la même longueur.

4. Norme d'un vecteur

Si un vecteur u a pour coordonnées (x ; y), sa norme est :

||u|| = √(x² + y²)
Pour u = (3 ; 4) :
||u|| = √(3² + 4²)
= √(9 + 16)
= √25 = 5.

5. Milieu d'un segment

Le milieu M de [AB] a pour coordonnées :

M((xA + xB)/2 ; (yA + yB)/2)

Leçon 7 : Géométrie plane

1. Le théorème de Pythagore

Dans un triangle rectangle, le carré de la longueur de l'hypoténuse est égal à la somme des carrés des longueurs des deux autres côtés.

AB² + AC² = BC²

Si BC est l'hypoténuse du triangle ABC rectangle en A.

AB = 3 cm et AC = 4 cm.
BC² = 3² + 4²
BC² = 9 + 16 = 25.
BC = 5 cm.

2. La réciproque de Pythagore

Si, dans un triangle, le carré du plus grand côté est égal à la somme des carrés des deux autres côtés, alors ce triangle est rectangle.

3. Le théorème de Thalès

Lorsque deux droites sécantes sont coupées par deux droites parallèles, les longueurs correspondantes sont proportionnelles.

AM/AB = AN/AC = MN/BC

4. La trigonométrie

Dans un triangle rectangle, pour un angle aigu α :

  • sin(α) = côté opposé / hypoténuse
  • cos(α) = côté adjacent / hypoténuse
  • tan(α) = côté opposé / côté adjacent
Dans un triangle rectangle, si le côté opposé à l'angle mesure 3 cm et l'hypoténuse 5 cm :
sin(α) = 3/5 = 0,6.

Leçon 8 : Statistiques

1. Définition

La statistique est une branche des mathématiques qui permet de recueillir, organiser, représenter et analyser des données.

2. Effectif et fréquence

L'effectif d'une valeur est le nombre de fois où cette valeur apparaît.

Fréquence = Effectif / Effectif total
Dans une classe de 40 élèves, 10 élèves ont obtenu 15/20.
La fréquence est :
10/40 = 0,25 = 25 %.

3. La moyenne

La moyenne d'une série statistique est la somme des valeurs divisée par leur nombre.

Moyenne = Somme des valeurs / Effectif total
Notes : 10 ; 12 ; 14 ; 16.
Moyenne = (10 + 12 + 14 + 16)/4
= 52/4 = 13.

4. La médiane

La médiane partage une série statistique ordonnée en deux groupes contenant chacun au moins la moitié des données.

Série : 4 ; 6 ; 8 ; 10 ; 12.
La valeur centrale est 8.
La médiane est donc 8.

5. L'étendue

L'étendue est la différence entre la plus grande valeur et la plus petite valeur.

Étendue = Maximum - Minimum
Pour la série 4 ; 6 ; 8 ; 10 ; 12 :
Étendue = 12 - 4 = 8.
