Leçon 1 : Ensembles de nombres et intervalles

Objectifs :
  • Connaître les principaux ensembles de nombres.
  • Savoir reconnaître un nombre et son ensemble.
  • Comprendre et utiliser les intervalles.

1. Les ensembles de nombres

En mathématiques, les nombres sont regroupés en plusieurs ensembles.

  • ℕ : nombres entiers naturels. Exemples : 0 ; 1 ; 2 ; 3 ; 15.
  • ℤ : nombres entiers relatifs. Exemples : -5 ; -2 ; 0 ; 4.
  • 𝔻 : nombres décimaux. Exemples : 2,5 ; -3,75 ; 0,25.
  • ℚ : nombres rationnels. Ce sont les nombres qui peuvent s'écrire sous la forme a/b avec a et b entiers et b différent de 0.
  • ℝ : nombres réels. Ils comprennent les nombres rationnels et irrationnels.

On a les inclusions suivantes :

ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ

Exemple :
  • 7 appartient à ℕ, ℤ, 𝔻, ℚ et ℝ.
  • -4 appartient à ℤ, 𝔻, ℚ et ℝ.
  • 2,5 appartient à 𝔻, ℚ et ℝ.
  • √2 appartient à ℝ mais pas à ℚ.

2. Les intervalles

Un intervalle est un ensemble de nombres réels compris entre deux bornes.

  • [a ; b] : les deux bornes sont incluses.
  • ]a ; b[ : les deux bornes sont exclues.
  • [a ; b[ : a est inclus et b est exclu.
  • ]a ; b] : a est exclu et b est inclus.
Exemple : x ∈ [2 ; 5] signifie que 2 ≤ x ≤ 5.
x ∈ ]2 ; 5[ signifie que 2 < x < 5.

3. Exercices corrigés

Exercice 1 : Dans quel ensemble se trouve le nombre -8 parmi ℕ, ℤ, 𝔻, ℚ et ℝ ?
-8 n'est pas naturel. C'est un entier relatif, donc il appartient à ℤ, 𝔻, ℚ et ℝ.
Exercice 2 : Traduire x ∈ [3 ; 7[ par une inégalité.
La réponse est : 3 ≤ x < 7.

À retenir

Les ensembles de nombres permettent de classer les nombres. Les intervalles permettent de représenter des ensembles de réels compris entre des bornes.

Leçon 2 : Calcul numérique et puissances

Objectifs :
  • Effectuer correctement des opérations numériques.
  • Utiliser les règles de priorité.
  • Manipuler les puissances.

1. Les opérations numériques

Les opérations fondamentales sont l'addition, la soustraction, la multiplication et la division.

2. Les priorités opératoires

Dans un calcul, on respecte généralement l'ordre suivant :

  1. Les calculs entre parenthèses.
  2. Les puissances.
  3. Les multiplications et divisions.
  4. Les additions et soustractions.
Exemple :
A = 3 + 2 × 5
On effectue d'abord la multiplication :
A = 3 + 10 = 13.

3. Les puissances

Une puissance permet d'écrire plus simplement une multiplication répétée.

Par exemple : 2³ = 2 × 2 × 2 = 8.

Pour un nombre a non nul :

  • aᵐ × aⁿ = aᵐ⁺ⁿ
  • aᵐ ÷ aⁿ = aᵐ⁻ⁿ
  • (aᵐ)ⁿ = aᵐˣⁿ
  • a⁰ = 1
  • a⁻ⁿ = 1/aⁿ
Exemple :
2³ × 2² = 2⁵ = 32.
(3²)³ = 3⁶ = 729.

4. La notation scientifique

Un nombre en notation scientifique s'écrit sous la forme a × 10ⁿ, avec 1 ≤ |a| < 10 et n entier.

Exemple :
45 000 = 4,5 × 10⁴.
0,0032 = 3,2 × 10⁻³.

5. Exercices corrigés

Exercice 1 : Calculer A = 5 + 3 × 4.
A = 5 + 12 = 17.
Exercice 2 : Simplifier 10³ × 10².
10³ × 10² = 10⁵ = 100 000.

Leçon 3 : Calcul littéral et factorisation

Objectifs :
  • Réduire une expression littérale.
  • Développer une expression.
  • Factoriser une expression.

1. Le calcul littéral

Le calcul littéral consiste à utiliser des lettres pour représenter des nombres.

Exemple : 3x + 2x = 5x.

2. Réduction d'une expression

Réduire consiste à regrouper les termes semblables.

Exemple :
A = 4x + 3 + 2x - 5
A = 4x + 2x + 3 - 5
A = 6x - 2.

3. Développement

Développer consiste à supprimer les parenthèses en utilisant la distributivité.

a(b + c) = ab + ac.

Exemple :
A = 3(x + 4)
A = 3x + 12.

4. Factorisation

Factoriser consiste à transformer une somme en produit.

Exemple :
A = 5x + 15
A = 5(x + 3).

5. Identités remarquables

  • (a + b)² = a² + 2ab + b²
  • (a - b)² = a² - 2ab + b²
  • (a - b)(a + b) = a² - b²
Exemple :
(x + 3)² = x² + 6x + 9.

6. Exercices corrigés

Exercice 1 : Développer A = 2(x + 5).
A = 2x + 10.
Exercice 2 : Factoriser B = 4x + 12.
B = 4(x + 3).

Leçon 4 : Équations et inéquations

Objectifs :
  • Résoudre une équation du premier degré.
  • Résoudre une inéquation simple.
  • Présenter correctement un ensemble de solutions.

1. Définition d'une équation

Une équation est une égalité contenant une ou plusieurs inconnues.

2. Résolution d'une équation

Pour résoudre une équation, on cherche la valeur de l'inconnue qui rend l'égalité vraie.

Exemple :
Résoudre 2x + 4 = 10.
2x = 10 - 4
2x = 6
x = 6/2
x = 3.
Vérification : 2 × 3 + 4 = 10.

3. Les inéquations

Une inéquation est une inégalité contenant une inconnue.

Les signes utilisés sont : <, >, ≤ et ≥.

Attention : lorsqu'on multiplie ou divise les deux membres d'une inéquation par un nombre négatif, on inverse le sens du signe.

Exemple :
Résoudre -2x > 6.
En divisant par -2, on inverse le signe :
x < -3.

4. Exercices corrigés

Exercice 1 : Résoudre 3x - 6 = 9.
3x = 9 + 6 = 15.
x = 15/3 = 5.
Exercice 2 : Résoudre x + 4 ≤ 9.
x ≤ 9 - 4.
x ≤ 5.

Leçon 5 : Généralités sur les fonctions

Objectifs :
  • Comprendre la notion de fonction.
  • Calculer une image.
  • Déterminer un antécédent.

1. Définition d'une fonction

Une fonction associe à chaque nombre x de son ensemble de définition un nombre unique appelé image de x.

On note généralement : f(x).

2. Calcul d'une image

Pour calculer l'image d'un nombre, on remplace x par ce nombre dans l'expression de la fonction.

Exemple :
Soit f(x) = 2x + 3.
Calculons l'image de 4.
f(4) = 2 × 4 + 3
f(4) = 8 + 3 = 11.

3. Déterminer un antécédent

Un antécédent de y est un nombre x tel que f(x) = y.

Exemple :
Soit f(x) = 2x + 3.
Cherchons l'antécédent de 9.
2x + 3 = 9
2x = 6
x = 3.

4. Représentation graphique

Une fonction peut être représentée dans un repère par une courbe. Les axes permettent de lire les images et les antécédents.

5. Exercices corrigés

Exercice 1 : Soit f(x) = 3x + 2. Calculer f(5).
f(5) = 3 × 5 + 2 = 15 + 2 = 17.
Exercice 2 : Soit f(x) = x + 4. Trouver l'antécédent de 10.
x + 4 = 10 donc x = 6.

Leçon 6 : Vecteurs et repérage

Objectifs :
  • Connaître la notion de vecteur.
  • Calculer les coordonnées d'un vecteur.
  • Utiliser les coordonnées dans un repère.

1. Définition d'un vecteur

Un vecteur est caractérisé par une direction, un sens et une longueur appelée norme.

2. Coordonnées d'un vecteur

Dans un repère, si A(xA ; yA) et B(xB ; yB), alors :

AB⃗ = (xB - xA ; yB - yA).

Exemple :
A(2 ; 1) et B(5 ; 4).
AB⃗ = (5 - 2 ; 4 - 1)
AB⃗ = (3 ; 3).

3. Égalité de deux vecteurs

Deux vecteurs sont égaux s'ils ont la même direction, le même sens et la même norme.

4. Norme d'un vecteur

Pour un vecteur u⃗ = (x ; y), sa norme est :

||u⃗|| = √(x² + y²).

Exemple :
Pour u⃗ = (3 ; 4) :
||u⃗|| = √(3² + 4²)
= √25 = 5.

5. Exercices corrigés

Exercice 1 : A(1 ; 2) et B(4 ; 6). Calculer les coordonnées de AB⃗.
AB⃗ = (4 - 1 ; 6 - 2) = (3 ; 4).
Exercice 2 : Calculer la norme du vecteur (6 ; 8).
√(6² + 8²) = √100 = 10.

Leçon 7 : Géométrie plane

Objectifs :
  • Connaître les propriétés des figures planes.
  • Utiliser le théorème de Pythagore.
  • Utiliser le théorème de Thalès.

1. Les triangles

Un triangle est un polygone qui possède trois côtés et trois angles.

  • Triangle équilatéral : trois côtés égaux.
  • Triangle isocèle : deux côtés égaux.
  • Triangle rectangle : un angle droit.

2. Théorème de Pythagore

Dans un triangle rectangle, le carré de la longueur de l'hypoténuse est égal à la somme des carrés des longueurs des deux autres côtés.

BC² = AB² + AC² si le triangle ABC est rectangle en A.

Exemple :
Un triangle rectangle possède deux côtés de longueurs 3 cm et 4 cm.
L'hypoténuse vaut :
c² = 3² + 4² = 9 + 16 = 25.
c = √25 = 5 cm.

3. Théorème de Thalès

Dans un triangle ABC, si M appartient à [AB], N appartient à [AC] et si (MN) est parallèle à (BC), alors :

AM/AB = AN/AC = MN/BC.

Exemple :
Si AM = 2 cm, AB = 4 cm et AC = 6 cm, alors :
AN/6 = 2/4
AN = 6 × 2/4
AN = 3 cm.

4. Exercices corrigés

Exercice 1 : Un triangle rectangle a pour côtés de l'angle droit 5 cm et 12 cm. Calculer son hypoténuse.
c² = 5² + 12² = 25 + 144 = 169.
c = √169 = 13 cm.
Exercice 2 : Dans une configuration de Thalès, AM/AB = 3/5 et AC = 10 cm. Calculer AN.
AN/10 = 3/5.
AN = 10 × 3/5 = 6 cm.

Leçon 8 : Statistiques

Objectifs :
  • Organiser une série statistique.
  • Calculer une moyenne.
  • Déterminer une médiane et une étendue.

1. Définition

Les statistiques permettent de recueillir, organiser et analyser des données.

2. La moyenne

La moyenne d'une série est égale à la somme des valeurs divisée par le nombre de valeurs.

Moyenne = Somme des valeurs / Effectif total.

Exemple :
Notes : 10 ; 12 ; 14 ; 16.
Moyenne = (10 + 12 + 14 + 16)/4
= 52/4
= 13.

3. La médiane

La médiane partage une série ordonnée en deux groupes contenant chacun environ la moitié des valeurs.

Exemple :
Série : 5 ; 8 ; 10 ; 12 ; 15.
La valeur centrale est 10.
Médiane = 10.

Si la série comporte un nombre pair de valeurs, la médiane est la moyenne des deux valeurs centrales.

4. L'étendue

L'étendue est la différence entre la plus grande et la plus petite valeur.

Exemple :
Série : 4 ; 6 ; 9 ; 12.
Étendue = 12 - 4 = 8.

5. Exercices corrigés

Exercice 1 : Calculer la moyenne des nombres 8 ; 10 ; 12 ; 14.
Moyenne = (8 + 10 + 12 + 14)/4 = 44/4 = 11.
Exercice 2 : Calculer l'étendue de la série 3 ; 7 ; 9 ; 15 ; 18.
Étendue = 18 - 3 = 15.
